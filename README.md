# Smart-Attendance-System-Using-Face-Recognition
A Java-based Smart Attendance System using OpenCV and Face Recognition to automatically identify students, record attendance, and maintain date-wise attendance records.
Smart Attendance System Using Face Recognition

Smart Attendance System is an AI-based attendance management application developed using Java and OpenCV. It uses facial recognition technology to identify students through a webcam and automatically record their attendance with date and time.

The system aims to reduce manual attendance work, save time, improve efficiency, and minimize duplicate attendance entries.

Key Features

* Real-time face detection using webcam.
* Automatic student face recognition.
* Attendance recording with date and time.
* Student identification using unique IDs.
* CSV-based attendance storage.
* Duplicate attendance prevention during a session.
* User-friendly attendance monitoring.

Technologies Used

* Java
* OpenCV
* LBPH Face Recognition
* Haar Cascade Classifier
* CSV File Handling

Objective

To develop an automated and efficient attendance management system using Artificial Intelligence and Computer Vision.

Future Scope

* Admin login and dashboard.
* Database integration.
* Excel attendance reports.
* Student registration module.
* Improved anti-spoofing and face verification.

Project Category: Artificial Intelligence and Machine Learning

Programming Language: Java
